# Player Movement

There are 2 major control schemes the player can move. Bedrock also supports multiple input devices.

### Button controls
Classic **WASD** button controls. Player can press 2 buttons at the same time to "strafe". This type of control is called "D-pad" for touchscreens.

There exists a glitch, [Triple Component Strafe](/Pages/triple_component_strafe.md). In this control scheme.

### Joystick controls
All direction movement controls. Available on mobile touchscreens, controller.

See [Joystick](/Pages/joystick.md) for full mechanic.
