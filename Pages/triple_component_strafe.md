# Triple component strafe

Is a glitch that allows strafing with 3 orthagonal input components. Normal strafe is made of 2 components (e.g. W + D). But with this glitch, you can do for example, W + W + D. The angle is `~26°` off the 4 main directions by this calculation,

$$\displaystyle \text{atan2}(\underbrace{2}_{\text{1st component}}, \underbrace{1}_{\text{2nd component}}) = \arctan\left(\frac{1}{2}\right) \approx 26.565^\circ$$

This glitch in particular does not give a speed/acceleration boost, but can be utillized greatly for easier jump strategies (e.g. easier jump angle, noturn, chained triple neos,...).

Can be either activated by using D-pad touch control, pressing in the region connecting W/S button and diagonal strafe button (still an unpatched glitch). Or use multiple input devices to combine inputs.
